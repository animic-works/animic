# Animic

お題のイラストをAI画像生成で再現し、再現度・提出速度・生成回数を競う対戦ゲームです。

## 開発

| 目的                             | 参照先                                                 |
| -------------------------------- | ------------------------------------------------------ |
| 初回セットアップ                 | [環境を用意する](CONTRIBUTING.md#環境を用意する)       |
| 実装・文書更新                   | [変更を実装する](CONTRIBUTING.md#変更を実装する)       |
| テスト・静的検査                 | [変更を検証する](CONTRIBUTING.md#変更を検証する)       |
| ブランチ・PR・レビュー           | [PRを出す](CONTRIBUTING.md#prを出す)                   |
| デプロイ・外部サービス・管理画面 | [リリース・運用する](CONTRIBUTING.md#リリース運用する) |

## 仕様と設計

[文書案内](docs/README.md)から、ゲーム仕様・アーキテクチャ・採点・デザイン原則・実装規約と、設計判断の記録を探せます。

文書の役割とテンプレートの使い方は[文書の管理](CONTRIBUTING.md#文書の管理)を参照してください。
